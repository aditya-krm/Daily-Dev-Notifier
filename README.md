# Daily Dev Notifier

[![Node.js](https://img.shields.io/badge/Node.js-20.x+-brightgreen.svg)](https://nodejs.org/)
[![ES Modules](https://img.shields.io/badge/ES-Modules-yellow.svg)](https://nodejs.org/api/esm.html)
[![PM2](https://img.shields.io/badge/PM2-Runtime-blue.svg)](https://pm2.keymetrics.io/)

A powerful, automated assistant that delivers personalized developer insights, tips, and career advice directly to your inbox. This Node.js application leverages Google's Gemini AI to generate high-quality, relevant content and delivers it on a randomized schedule.

## 🌟 What I Learned & Why It Matters

Building this project taught me several valuable lessons that can benefit other developers:

**Turning Notifications into Learning Opportunities**: In a world flooded with notifications—many of which are irrelevant or distracting—this project flips the script by transforming notifications into a source of daily learning. By automating emails with insightful, developer-focused content, it ensures that every notification adds value to your day instead of cluttering your inbox.

1. **AI Integration in Practical Workflows**: Instead of just experimenting with AI, I built a practical system that delivers value every day through curated content.

2. **Modular JavaScript Architecture**: The project demonstrates how to structure a Node.js application using ES modules in a clean, maintainable way with proper separation of concerns.

3. **Working with Image Processing in Emails**: I learned how to handle base64 images generated by AI and properly embed them in HTML emails using CID references, ensuring emails display correctly.

4. **Randomized Task Scheduling**: Using node-cron to create dynamic, randomized schedules that still follow specific business rules.

5. **Proper Logging and Monitoring**: Implementing Winston for structured logging to facilitate debugging and monitoring of a long-running process.

## ✨ Features

- **AI-Powered Content**: Uses Google's Gemini AI to generate high-quality, relevant developer content
- **Diverse Topics**: Rotates between 7 different developer-focused topics:
  - 🔍 Dev Insight or Tip of the Day
  - ⚛️ React/Next.js/Node/PostgreSQL/DevOps tips
  - 🤖 Web or AI trend/tool explanations
  - 🧠 Soft skill or focus techniques
  - 🛠️ Technical blog post-style write-ups
  - 📈 Career or job-prep tips
  - 💡 Motivation, quotes, or real dev stories
- **Intelligent Scheduling**: Automatically delivers the specified number of emails per day (configured via environment variables) at randomized intervals within business hours, ensuring timely and effective communication.
- **Rich HTML Emails**: Delivers professionally formatted content with proper html and style handling
- **Comprehensive Logging**: Tracks all activity and email history
- **Set-and-Forget**: Designed for long-running deployment with PM2

## 📋 Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/aditya-krm/Daily-Dev-Notifier.git
   cd `directory`
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Create a `.env` file with your credentials(see example):

4. Run the application:
   - `npm start` - Start the application
   - `npm run dev` - Start with nodemon for development
   - `npm run manual` - Manually trigger a single notification
   - `npm run start:pm2` - Start with PM2 process manager
   - `npm run stop:pm2` - Stop the PM2 process
   - `npm run logs` - View PM2 logs
